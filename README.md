# APBD – Ćwiczenia 1: Git i GitHub

Repozytorium z ćwiczeń z Gita: tworzenie repozytorium, zapisywanie zmian w commitach,
scalanie gałęzi (fast-forward i three-way merge) oraz ręczne rozwiązywanie konfliktu.

## Opis programu

**GitPractice** to prosta aplikacja konsolowa w C#. Wyświetla powitanie oraz statystyki
tablicy liczb całkowitych zdefiniowanej w `Program.cs`. Obliczenia znajdują się w klasie
`StatisticsHelper`, a tekst powitania w klasie `Greeting`.

## Wymagania

- [.NET SDK](https://dotnet.microsoft.com/download) w wersji 10.0 lub nowszej
- Git

## Uruchomienie

```bash
git clone https://github.com/s17971/apbd-cw1-git.git
cd apbd-cw1-git
dotnet run
```
